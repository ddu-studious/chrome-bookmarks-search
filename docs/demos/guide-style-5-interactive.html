快速开始

三步开始使用 Chrome Bookmarks Search

步骤

  • 唤起搜索 — 按下 Alt + B（macOS: Option + B）
  • 输入关键字 — 结果实时过滤，支持中英文混合
  • 打开结果 — ↑↓ 选择，Enter 打开

窗口模式

在配置中心可选择「独立窗口模式」或「弹出面板模式」。独立窗口支持调整大小和位置记忆。

搜索模式

按 Tab 切换模式

书签搜索

搜索浏览器保存的所有书签，支持健康检测标签（未使用、很少使用、休眠）。

标签页搜索

搜索当前打开的所有标签页。点击结果可直接切换到对应标签。

历史记录

搜索最近浏览历史，默认 30 天。时间范围可在设置中调整。

下载搜索

搜索已下载的文件，支持按文件类型（PDF、图片、文档等）显示不同图标。

AI 搜索

语义搜索模式，理解你的搜索意图而非仅匹配关键词。需在设置中配置 API Key。

快捷键

提高效率的键盘操作

Alt + B 打开/关闭搜索
↑ ↓ 上下选择结果
Tab 下一个模式
Shift+Tab 上一个模式
Enter 打开选中项
Esc 关闭窗口
Ctrl/⌘ + Click 多选
Shift + Click 范围选择

搜索语法

使用高级语法精确过滤结果

site:github.com 限定特定网站
type:pdf 按文件类型过滤
in:title 关键词 仅搜索标题
in:url 关键词 仅搜索 URL
after:2024-01 某日期之后
before:2024-06 某日期之前
"精确词组" 引号内整体匹配
-排除词 排除包含该词的结果

多平台搜索

输入前缀 + 关键词，Enter 跳转

g: 关键词 Google 搜索
gh: 关键词 GitHub 搜索
yt: 关键词 YouTube 搜索
bd: 关键词 百度搜索
zh: 关键词 知乎搜索
bl: 关键词 哔哩哔哩搜索
npm: 关键词 NPM 搜索
mdn: 关键词 MDN Web Docs
so: 关键词 Stack Overflow

自定义平台

在配置中心 → 多平台搜索中，可以添加自定义搜索平台。设置前缀、名称和搜索 URL（使用 {query} 作为关键词占位符）。

批量操作

高效管理多个搜索结果

多选

  • Ctrl/⌘ + Click — 逐个选择/取消选择
  • Shift + Click — 范围选择（从上次选中到当前点击之间的所有项）

批量操作

  • 批量打开 — 在新标签页中打开所有选中的书签
  • 复制链接 — 将所有选中项的 URL 复制到剪贴板

右键菜单

右键点击搜索结果可打开上下文菜单，提供「打开」「复制链接」「复制标题」「在新窗口打开」等操作。
