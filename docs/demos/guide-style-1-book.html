Chapter 1

快速开始

三步即可开始使用 Chrome Bookmarks Search 高效管理你的浏览数据。

1
唤起搜索

按下 Alt + B（可自定义快捷键），搜索窗口即刻弹出。

2
输入关键字

直接输入搜索词，结果实时过滤。支持多关键字、高级语法和排除语法。

3
选择并打开

用 ↑ ↓ 选择结果，Enter 打开。也可直接鼠标点击。

Chapter 2

搜索模式

使用 Tab / Shift+Tab 在五种模式间快速切换。

书签搜索

搜索所有保存的书签。结果包含访问统计（未使用、很少使用、休眠等状态标签）。支持按文件夹路径、站点等过滤。

标签页搜索

搜索当前打开的所有标签页。点击结果可切换到对应标签，避免重复打开相同网页。

历史记录

搜索最近的浏览历史。时间范围可在设置中调整（默认 30 天）。

下载搜索

搜索下载的文件，按文件类型显示不同图标。支持 type: 语法按格式过滤。

Chapter 3

搜索语法

使用高级搜索语法精确定位你需要的内容。

语法说明示例
site:域名限定特定网站site:github.com react
type:类型按文件类型过滤type:pdf 报告
in:title仅搜索标题in:title 会议纪要
in:url仅搜索 URLin:url github
after:日期某日期之后after:2024-01
before:日期某日期之前before:2024-06
"精确词组"引号内整体匹配"machine learning"
-排除词排除包含该词的结果react -native
提示

语法可以组合使用，例如 site:github.com type:pdf after:2024-01 报告

Chapter 4

快捷键

掌握快捷键，让你的操作效率翻倍。

Alt + B 打开/关闭搜索
↑ ↓ 上下选择结果
Tab 切换搜索模式
Enter 打开选中项
Esc 关闭搜索窗口
Ctrl/⌘ + Click 多选项目
Shift + Click 范围选择
右键点击 打开操作菜单
Chapter 5

多平台搜索

输入平台前缀 + 冒号即可快捷跳转到其他搜索平台。

在搜索框中输入前缀（如 gh:）后跟关键词，按 Enter 即可跳转到对应平台搜索。

前缀平台
g:Google
gh:GitHub
yt:YouTube
bd:百度
zh:知乎
npm:NPM
Chapter 6

批量操作

使用多选功能批量处理搜索结果。

按住 Ctrl / ⌘ 点击可多选结果，选中后可批量打开链接或复制 URL。使用 Shift + Click 可进行范围选择。
