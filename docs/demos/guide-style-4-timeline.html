学习路径 — 从入门到精通

入门

快速开始

按下 Alt + B 唤起搜索 → 输入关键字实时过滤 → ↑↓ 选择 + Enter 打开。

就这么简单，三步即可开始使用。

入门

搜索模式

使用 Tab / Shift+Tab 切换五种模式：书签、标签页、历史记录、下载、AI 搜索。

每种模式聚焦不同数据源，精准快速定位内容。

入门

快捷键

Alt+B 打开/关闭
↑ ↓ 选择结果
Tab 切换模式
Enter 打开选中
Esc 关闭窗口
Ctrl+Click 多选
进阶

搜索语法

site:域名 限定网站
type:类型 文件类型
in:title 搜索标题
in:url 搜索 URL
after:日期 日期之后
before:日期 日期之前
"词组" 精确匹配
-排除 排除结果
进阶

多平台搜索

输入 前缀: + 关键词，按 Enter 跳转到对应平台。

g: Google
gh: GitHub
yt: YouTube
bd: 百度
zh: 知乎
npm: NPM
高级

批量操作

Ctrl/⌘ + Click 多选，Shift + Click 范围选择。选中后可批量打开链接或复制 URL。右键菜单提供更多操作选项。
