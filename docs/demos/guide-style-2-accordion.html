Chrome Bookmarks Search

全面了解扩展的功能和使用技巧

快速开始

3 个步骤即可上手
  • 唤起搜索 — 按下 Alt + B，搜索窗口即刻弹出
  • 输入关键字 — 输入搜索词，结果实时过滤，支持多关键字和高级语法
  • 选择并打开 — 用 ↑ ↓ 选择，Enter 打开

搜索模式

5 种模式满足不同需求

使用 Tab / Shift+Tab 在模式间快速切换：

  • 书签 — 搜索所有保存的书签，显示访问统计和状态标签
  • 标签页 — 搜索当前打开的标签页，点击可切换过去
  • 历史记录 — 搜索最近浏览历史（可调时间范围）
  • 下载 — 搜索下载的文件，按类型显示图标
  • AI — 语义搜索，理解你的意图

搜索语法

8 种高级过滤语法
site:github.com限定特定网站
type:pdf按文件类型过滤
in:title仅搜索标题
in:url仅搜索 URL
after:2024-01某日期之后
before:2024-06某日期之前
"精确词组"引号内整体匹配
-排除词排除含该词的结果

快捷键

键盘操作效率更高
Alt + B 打开/关闭
↑ ↓ 选择结果
Tab 切换模式
Enter 打开选中
Esc 关闭窗口
Ctrl+Click 多选
Shift+Click 范围选择
右键 操作菜单

多平台搜索

输入 前缀: + 关键词，按 Enter 即可跳转。
