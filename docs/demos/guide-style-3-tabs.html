使用说明

全面了解 Chrome Bookmarks Search 的功能和使用技巧

三步开始搜索

Chrome Bookmarks Search 让你以最快的速度找到书签、标签页、历史记录和下载文件。

1

唤起搜索

按下 Alt + B

2

输入关键字

结果实时过滤

3

打开结果

Enter 或点击

书签搜索

搜索所有保存的书签。结果包含访问统计（未使用、很少使用、休眠等状态标签）。

标签页搜索

搜索当前打开的所有标签页。点击结果可切换到对应标签。

历史记录

搜索最近的浏览历史。时间范围可在设置中调整。

下载搜索

搜索下载的文件，按文件类型显示不同图标。

AI 搜索

语义搜索，理解你的搜索意图，不仅匹配关键词。

分组搜索

搜索 Chrome 标签页分组（需在设置中开启）。

site:github.com限定特定网站
type:pdf按文件类型过滤
in:title 会议仅搜索标题
in:url github仅搜索 URL
after:2024-01某日期之后的结果
before:2024-06某日期之前的结果
"精确词组"引号内作为整体匹配
-排除词排除包含该词的结果
Alt + B 打开/关闭搜索
↑ ↓ 上下选择结果
Tab 切换搜索模式
Enter 打开选中项
Esc 关闭搜索窗口
Ctrl/⌘ + Click 多选项目
Shift + Click 范围选择
右键点击 打开操作菜单

多平台快捷跳转

在搜索框输入 前缀: + 关键词，按 Enter 即可跳转到对应平台搜索。

g: Google
gh: GitHub
yt: YouTube
bd: 百度
zh: 知乎
bl: 哔哩哔哩
npm: NPM
mdn: MDN
so: Stack Overflow
