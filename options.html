Chapter 1

快速开始

三步即可开始使用 Chrome Bookmarks Search 高效管理你的浏览数据。

1
唤起搜索

按下 Alt + B（可自定义快捷键），搜索窗口即刻弹出。

2
输入关键字

直接输入搜索词，结果实时过滤。支持多关键字、高级语法和排除语法。

3
选择并打开

用 ↑ ↓ 选择结果，Enter 打开。也可直接鼠标点击。

Chapter 2

搜索模式

使用 Tab / Shift+Tab 在五种模式间快速切换。

书签搜索

搜索所有保存的书签。结果包含访问统计（未使用、很少使用、休眠等状态标签）。

标签页搜索

搜索当前打开的所有标签页。点击结果可切换到对应标签。

历史记录

搜索最近的浏览历史。时间范围可在设置中调整（默认 30 天）。

下载搜索

搜索下载的文件，按文件类型显示不同图标。支持 type: 语法按格式过滤。

Chapter 3

搜索语法

使用高级搜索语法精确定位你需要的内容。

语法说明示例
site:域名限定特定网站site:github.com react
type:类型按文件类型过滤type:pdf 报告
in:title仅搜索标题in:title 会议纪要
in:url仅搜索 URLin:url github
after:日期某日期之后after:2024-01
before:日期某日期之前before:2024-06
"精确词组"引号内整体匹配"machine learning"
-排除词排除包含该词的结果react -native
tag:标签按书签标签过滤tag:工作 react
提示

语法可以组合使用，例如 site:github.com type:pdf after:2024-01 报告

Chapter 5

多平台搜索

输入平台前缀 + 冒号即可快捷跳转到其他搜索平台。

在搜索框中输入前缀后跟关键词，按 Enter 即可跳转。

前缀平台
g:Google
gh:GitHub
yt:YouTube
bd:百度
zh:知乎
npm:NPM

支持 12 个内置平台，还可在多平台搜索设置中自定义添加。

Chapter 6

批量操作

使用多选功能批量处理搜索结果。

按住 Ctrl / ⌘ 点击可多选结果，使用 Shift + Click 可范围选择。选中后工具栏支持批量打开、批量复制链接。右键点击可编辑或删除书签。

Chapter 7

书签标签

为书签添加自定义标签，实现更灵活的分类管理。

添加标签

在书签搜索模式下，右键点击书签选择"管理标签"，可以添加、删除标签。也可以从预设的标签调色板中快速选择。

按标签搜索

使用 tag:标签名 语法过滤书签。tag:* 查找有标签的书签，tag:! 查找无标签的书签。

管理标签调色板

在配置中心的"书签整理"页面可以管理标签调色板、查看标签使用统计。

Chapter 8

智能整理

自动分析并整理书签到合适的文件夹中。

分析与预览

在配置中心点击"分析并预览"，系统会根据域名和关键词分析书签，生成整理方案供预览。确认无误后再执行。

自定义域名映射

在"域名分类映射"中添加自定义规则，例如将 github.com 归类到"开发工具"文件夹。

备份与撤销

每次整理前会自动备份当前书签结构，支持一键撤销恢复。

Chapter 9

AI 智能搜索

使用自然语言搜索书签，无需精确关键字。

启用 AI 搜索后，支持语义理解搜索。首次使用需构建向量索引，之后搜索速度极快。支持 Gemini、OpenAI、SiliconFlow 等多个服务商，使用你自己的 API Key，数据不经第三方。

Chapter 10

实用技巧

一些能让你事半功倍的使用技巧。

智能排序 — 结合标题相关度、访问频率和最近访问时间综合排序。

界面风格 — 支持 Spotlight / Raycast / Fluent 三种风格，可切换字体。

搜索窗口模式 — 独立窗口或弹出面板，在常规设置中切换。

组合语法 — 多种搜索语法可组合，如 site:github.com after:2024-01 -fork tag:收藏。

友情链接 — 自定义搜索窗口底部的快捷链接，方便一键访问。
