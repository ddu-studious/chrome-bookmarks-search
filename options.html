使用说明

全面了解 Chrome Bookmarks Search 的功能和使用技巧

快速开始

1
唤起搜索

按下 Alt + B（可在常规设置中修改），即可在任意网页上唤起搜索浮层。

2
输入关键字

直接输入搜索词，结果会实时过滤。支持多关键字、高级语法和排除语法。

3
选择并打开

用 ↑ ↓ 选择结果，Enter 打开。也可以直接鼠标点击。

五大搜索模式

使用 ← → 方向键快速切换模式：

  • 书签 - 搜索所有保存的书签，显示访问统计和状态标签
  • 标签页 - 搜索当前打开的所有标签页，点击可切换到对应标签
  • 历史记录 - 搜索最近浏览历史（时间范围可在设置中调整）
  • 下载 - 搜索下载的文件，按文件类型显示不同图标
  • 分组 - 搜索 Chrome 标签页分组（需在设置中开启）

快捷键指南

Alt + B打开/关闭搜索
↑ ↓上下选择结果
← →切换搜索模式
Enter打开选中项
Esc关闭搜索窗口
Ctrl/⌘ + Click多选项目
Shift + Click范围选择
右键点击打开操作菜单

搜索语法

关键字1 关键字2 多关键字同时匹配 (AND)
"精确词组" 引号内作为整体精确匹配
-排除词 排除包含该关键字的结果
-词1,词2,词3 逗号分隔，一次排除多个关键字
-"词组1,词组2" 逗号分隔，排除多个精确词组
site:github.com 限定网站搜索
in:title / in:url 限定仅搜索标题或网址
after:2024-01 指定日期之后的结果
before:2024-06 指定日期之前的结果
type:pdf 下载模式中按文件类型过滤

搜索引擎跳转

当本地搜索没有结果时，可以一键跳转到外部搜索引擎继续搜索：

  • 有结果时 - 搜索结果底部显示"使用 Google/百度 搜索"跳转项
  • 无结果时 - 顶部醒目显示搜索引擎跳转入口
  • URL 识别 - 输入网址格式的文字（如 github.com），顶部出现"打开链接"选项，可直接在新标签页打开
  • 可配置 - 在常规设置中选择默认搜索引擎（Google / 百度 / Bing / DuckDuckGo）

批量操作

选中多个结果后可执行批量操作：

  • Ctrl/⌘ + 点击 逐一多选，Shift + 点击 范围选择
  • 选中后弹出工具栏，支持批量打开、批量复制链接
  • 在书签模式下右键点击可编辑或删除书签
  • 在历史/下载模式下右键可删除对应记录

界面风格

点击搜索浮层右下角的调色盘按钮切换风格，或在外观设置中选择：

  • Spotlight - macOS 风格，毛玻璃效果，简约优雅
  • Raycast - 命令面板风格，深色主题，开发者最爱
  • Fluent - Windows 11 风格，亚克力效果，现代感

还可以切换字体：点击浮层右下角的 Aa 按钮循环切换系统默认、苹方、Inter、Noto 等字体。

书签状态智能分析

扩展会根据浏览历史自动分析每个书签的使用状态：

  • 未使用 - 从未访问过的书签，可能是过时链接
  • 很少使用 - 访问次数少于 3 次
  • 休眠 - 超过 180 天未访问，建议清理或归档
  • 活跃 - 正常使用的书签

在书签搜索模式中，可以通过筛选按钮快速过滤出不同状态的书签。

实用技巧

  • 智能排序 — 结合标题相关度、访问频率和最近访问时间综合排序，最可能需要的结果排在前面
  • 最近访问提示 — 在书签/标签页模式下搜索时，底部会自动补充匹配的最近浏览历史
  • 组合语法 — 多种语法可组合使用，例如 site:github.com after:2024-01 -fork
  • 友情链接 — 在设置中自定义搜索窗口底部的快捷链接，方便一键访问常用网站
  • 降级兜底 — 在 chrome:// 等无法注入浮层的页面，自动使用独立搜索窗口
